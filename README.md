### 🔴 REVO: College Store App
A mobile ordering platform for college campuses, like Swiggy or Zomato but locked inside the campus. Students order from their phones and show up only when their token is called.

**Highlights**
- 🏫 Built with a friend for a real campus (JNN College of Engineering), solving long queues, cash-only payments, and refund chaos at the college store
- ⚡ Live order tracking (`pending → preparing → ready → collected`) with no refreshing
- 🎟️ Token-based pickup and in-app wallet payments (Razorpay-ready)
- 🔒 Atomic order placement in PostgreSQL and Row Level Security on every table
- 🤖 Auto-expiry of uncollected orders with automatic wallet refunds, plus push notifications

**Tech Stack:** Flutter · Supabase (PostgreSQL, Auth, Realtime, Edge Functions) · Firebase Cloud Messaging · pg_cron

🔗 **Repo:** [vedamurthym/REVO-](https://github.com/vedamurthym/REVO-)

### 📜 Chandas Anveshana
A Chandas detector based on Chandashastra. Give it a Sanskrit or transliterated verse and it identifies the meter.

**Highlights**
- 🥈 **2nd prize** at the department-level hackathon
- 🔤 Accepts verses of 1-4 lines and splits them into syllables
- 🎼 Finds the Laghu/Guru pattern to detect Anushtubh, Indravajra, or Upendravajra, and returns Unknown otherwise

🔗 **Repo:** [vedamurthym/chandas-anveshana](https://github.com/vedamurthym/chandas-anveshana)
